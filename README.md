# Sales Performance Dashboard – Power BI

## Project Overview
This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI. The dashboard provides insights into overall sales performance, order trends, product categories, and regional sales distribution.

## Key Performance Indicators (KPIs)
- **Total Sales:** 3.21M
- **Total Orders:** 100
- **Total Quantity Sold:** 335
- **Average Sales per Order:** 32.14K

## Dashboard Features
- Sales by Category – Analyzes sales performance across Electronics, Furniture, and Stationery.
- Monthly Sales Trend – Displays monthly sales performance from January to June.
- Sales by Region – Compares sales distribution across North, East, South, and West regions.
- Interactive Filters – Month and Region slicers allow users to explore specific sales data.
